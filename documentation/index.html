3. Changing Logo & Fonts

The template uses vector icon monograms + Google Fonts. To change the brand text or logo image in any header: 

<a class="navbar-brand navbar-brand-logo" href="index.html">
  <i class="bi bi-gem text-gold"></i>
  <span>YOUR BRAND</span> STORE
</a>

To use a custom PNG or SVG image logo: 

<a class="navbar-brand" href="index.html">
  <img src="assets/images/logo.png" alt="Brand Logo" height="42">
</a>

4. Customizing Color Palette

All brand colors are controlled via CSS custom properties in assets/css/style.css: 

:root {
  --color-terracotta: #C26D53;       /* Main brand accent */
  --color-terracotta-hover: #A9563E;
  --color-gold: #C5A880;             /* Luxury gold accent */
  --color-sand: #D8C5B4;             /* Earthy neutral tone */
  --bg-body: #FAF7F2;                /* Warm ivory background */
}

[data-theme="dark"] {
  --bg-body: #141210;                /* Deep obsidian charcoal */
  --bg-surface: #1E1B18;             /* Dark card surface */
  --color-terracotta: #D77F64;
}

6. Dark Mode & RTL Support

Dark mode and RTL are powered by assets/js/theme.js. The user preference is saved automatically in localStorage.

  • Toggle Theme: Click any element with data-action="toggle-theme".
  • Toggle RTL: Click any element with data-action="toggle-rtl".

7. Custom Rug Sizing Calculator

Located in custom-sizing.html and powered by assets/js/validation.js. It computes square footage from width × length in Feet, Meters, or Inches, applies material multipliers (Silk = $28/sq ft, Wool = $12.50/sq ft, Jute = $7.50/sq ft), and feeds the quote modal automatically.

8. Showroom Booking & Forms

The Showroom Appointment form in contact.html runs handleShowroomBooking(event). It validates required inputs, generates an appointment reference code (e.g. RCS-849201), and displays an instant confirmation modal with reservation recap.

9. Admin Dashboard & Charts

The admin directory (admin/) contains 8 full pages. Visual charts are powered by Chart.js 4.x linked via CDN and configured in assets/js/dashboard.js. The dashboard automatically syncs with the user's Dark/Light mode preference.
